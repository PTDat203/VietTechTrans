# Báo cáo quyết định (DR)

Mỗi lựa chọn công nghệ đưa vào code có một báo cáo mini (sketch2: "khi chọn và
áp dụng vào code phải có báo cáo mini"). Viết theo
[DR-00_template.md](DR-00_template.md). Một mốc chỉ xong khi DR của mốc đó đã viết.

| DR | Chủ đề | Mốc viết | Trạng thái |
|---|---|---|---|
| DR-01 | Nền tảng app | M0 | [đã chốt](DR-01_nen_tang_app.md) |
| DR-02 | Runtime giọng nói | M2 | chưa viết |
| DR-03 | STT (VI + EN + VAD) | M4 | chưa viết |
| DR-04 | TTS (+ espeak-ng, lexicon) | M3 | chưa viết |
| DR-05 | Hội thoại & chen lời | M6 | chưa viết |
| DR-06 | Lịch sử | M7 | chưa viết |
| DR-07 | Engine dịch & gói MT | M5 | chưa viết |
| DR-08 | Đo đạc & evidence | M8 | chưa viết |

Quy ước:

- Tên file `DR-NN_<chu_de>.md` (không dấu), ví dụ `DR-01_nen_tang_app.md`.
- DR đã chốt không sửa nội dung quyết định. Khi đổi lựa chọn, viết DR mới và
  ghi "thay thế bởi DR-xx" ở DR cũ.
